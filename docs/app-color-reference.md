Riferimento: screenshot nella cartella Desktop `Screen app IPAD`.
Schermate esaminate: IMG_0354, IMG_0355, IMG_0359, IMG_0361,
IMG_0366, IMG_0368 e IMG_0370.

Valori campionati da IMG_0355.PNG (profilo sRGB):

| Ruolo | Colore |
| --- | --- |
| Pulsanti primari e selezioni | `#6D20EC` |
| Sfondo delle schermate chiare | `#F5F5F5` |
| Campi di input | `#F9F9F9` |
| Card | `#FFFFFF` |
| Testo principale | `#131316` |
| Testo secondario | `#636369` |

La schermata IMG_0361.PNG mostra una sfumatura dal viola al quasi nero:
sono stati campionati `#2F0C6B` nella zona intermedia e `#090019` in basso.
Questi colori vengono usati per la hero fotografica della home.
Chi siamo, Contatti e le altre superfici informative rimangono chiare.

I token `--wayout-*` in `resources/css/app.css` alimentano i componenti
condivisi e la palette Tailwind. Tinte chiare dei controlli e stato hover
sono derivati dal viola primario; non rappresentano nuovi colori di marca.
Nessuno screenshot o dato personale è stato copiato nel progetto.
